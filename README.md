# GenAI-Powered Full-Stack Web Application

A full-stack web application combining modern web development with Generative AI to provide intelligent, interactive functionality.

## 🚀 Features

- User authentication
- JWT-based authorization
- Protected API routes
- Responsive React interface
- RESTful backend APIs
- MongoDB data persistence
- AI-powered functionality
- Input validation and error handling

## 🤖 Generative AI

The application integrates Google's Gemini API to provide AI-powered functionality based on user input and application context.

## 🛠️ Tech Stack

### Frontend
- React.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### AI
- Google Gemini API

### Authentication
- JWT

## 🏗️ Architecture

React.js
   ↓
REST APIs
   ↓
Express.js
   ↓
Node.js
   ↓
MongoDB

        ↘ Gemini API

## ⚙️ Setup

### Clone

git clone YOUR_REPOSITORY_URL

### Install dependencies

npm install

### Environment Variables

Create a `.env` file:

MONGODB_URI=
JWT_SECRET=
GEMINI_API_KEY=

### Run

npm run dev
